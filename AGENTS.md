# Diretrizes do Projeto

## 1. Versionamento Git Rigoroso
- Commit Imediato: Apos QUALQUER alteracao em arquivos do projeto (edicao, adicao, remocao ou correcao), execute obrigatoriamente git add e git commit com uma mensagem clara e descritiva em portugues.
- Nenhum arquivo solto: Nunca finalize uma resposta deixando modificacoes pendentes sem commit no Git.
- Historico Limpo: Garanta que cada etapa funcional tenha seu respectivo commit registrado no historico do repositorio.

## 2. Restricoes de Estilo
- Zero Emojis: Nao utilizar nenhum emoji em respostas, artefatos, codigos-fonte ou mensagens de commit.
